# 📚 Documentation

This folder contains all design and analysis documents for the FoodHub Database System.

## Contents

| File | Description |
|------|-------------|
| `user-requirements.md` | Functional and non-functional requirements from the user's perspective |
| `system-requirements.md` | Technical and system-level requirements |
| `er-diagram.png` | Entity-Relationship diagram (conceptual design) |
| `logical-design.md` | Logical schema with primary keys, foreign keys, and referential integrity |
| `normalization-report.md` | Proof of normalization from 1NF to 3NF with anomaly removal |
| `data-dictionary.md` | Complete data dictionary for all tables and columns |

## Purpose

These documents capture the complete design process — from understanding what the client needs, to designing a normalized relational database ready for implementation.
